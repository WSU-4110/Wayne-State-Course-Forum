WAYNE STATE COURSE FORUM 
CSC 4110 - Software Engineering - Wayne State University
Fall 2026 
Project Status: In development 


PROJECT OVERVIEW
The Wayne State Course Forum is a web application created with the intention to help Wayne State University students learn and share their class experiences with others. Instead of searching multiple websites or media, students will be able to look up specific Wayne State courses and find discussions in one place.

PURPOSE
This project aims: 
To make it easier to find information and student perspectives about Wayne State courses
To let students share their advice about course workload, preparation, studying, and expectations
To provide a groundwork for a searchable, student-centered course discussion community.

FUNCTIONALITY 
Homepage: Wayne State University landing page with navigation to site pages and university news/events
Course Search: Users shall be able to search for real Wayne State courses using subject abbreviation and course number 
Course validation: backend confirms whether a requested course exists using saved course records in Neon database. When needed, course information shall be retrieved from the official Wayne State University course bulletin website.
Course pages: Every course shall have specific pages to display available course information and retrieve discussion posts that are associated with them.

TECHNOLOGY STACK
Frontend - HTML, CSS, JavaScript, hosted on GitHub Pages
Backend - Node.js, Express.js, hosted on Render
Database - PostgresSQL, hosted on Neon 
VCS - GitHub
