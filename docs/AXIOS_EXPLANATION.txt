what is axios? 
popular, promise-based JavaScript library used to make HTTP/HTTPS requests from both browser and Node.js environments

axios is a javascript library for making HTTPS requests. obviously HTTPS is the protocol for web browser data transfer or whatever 
browsers know how to make HTTPS requests automatically but we're using a javascript program to do it instead. so thats why we need axios 

axios.get() sends an HTTP GET request to the URL that it is given back whatever response from the server
